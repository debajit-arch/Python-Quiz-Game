# Python-Quiz-Game
A terminal-based Python quiz game that tests basic computer knowledge through 10 open-ended questions — no multiple choice, you type your own answers — and shows your score and performance percentage at the end.

##🧠 Python Quiz Game:-

A simple terminal-based quiz game built in Python that tests your basic computer knowledge. Unlike typical MCQ-style quizzes, this one asks you to type your own answers — putting your knowledge to a real test, not just recognition!

##📌 About the Project:-

This is my first personal Python project. The game asks the user 10 questions related to basic computer knowledge. Instead of picking from multiple-choice options, the user types their answer directly. At the end, the game displays the number of correctly answered questions along with a performance percentage.

##⚙️ How It Works:-

1. The program greets the user and asks if they want to play.
2. If the user types yes, the quiz begins.
3. The user is asked 10 questions, one at a time, based on basic computer knowledge.
4. For each question, the user types their answer (no options are shown).
5. Once all questions are answered, the program displays:
6. Total number of correct answers
7. Performance percentage based on the score

##🚀 Features:-

1. Interactive command-line quiz experience
2. Typed-answer format (no multiple choice) — tests actual recall, not guesswork
3. Automatic score calculation
4. Performance percentage displayed at the end
5. Simple, beginner-friendly Python logic

##🛠️ Built With:-

2 .No external libraries required — built using core Python
